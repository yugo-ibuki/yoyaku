# 制作仕様

## 画面

- 縦型 720×1280、24fps、H.264/AAC、目標約3分。実際の長さは最終音声に一致させる。
- `assets/base.png`、`left-speaking.png`、`right-speaking.png` は元のDINING/FOOD画像（941×1672）の同一構図を維持する。
- 左のオレンジ猫が `left_student`、右のグレー猫が `right_teacher`。位置、毛色、背景、小物を変更しない。
- 発話中は完成済みの話者ポーズをターン単位で表示し、ターン間はbase画像へ戻す。
- 画面に出す話者名は「生徒」「先生」だけ。内部IDや声の年齢・性別は表示しない。
- 字幕は下部の安全領域に最大2行で表示し、同じ検証済みタイムラインで話者ポーズの切り替えと字幕を駆動する。

## 音声

- `left_student`: 若い女性。明るく、疑問と発見が伝わるテンポ。
- `right_teacher`: 年上の男性教師。穏やかで、生徒より少し遅いテンポ。
- 台本16ターンを順番どおりに収録する。話者交代が聞き分けられる自然な間を置く。
- 最終音声は `audio/ai-studio-original.wav`。この原本のハッシュを基準にすべての派生タイミングを作る。

## タイミング工程

1. 最終音声と [DIALOGUE.md](DIALOGUE.md) の一致を聞いて確認する。
2. 声と文脈で16ターンの開始・終了を確認し、`verified_turns.json` を作る。無音だけで話者交代を決めない。
3. `align_dialogue.py` で各ターン内の字幕カード先頭を強制アラインする。
4. 低信頼境界は波形、前後の発話、聞き取り結果を人が確認し、根拠を記録する。
5. `render.py` で最終音声、アラインメント、画像を組み合わせる。
6. `verify_timeline.py` で音声ハッシュ、台本、字幕連続性、話者交代、動画ストリーム、全体時間を検証する。

音声変更時は `verified_turns.json`、アラインメント、メタデータ、動画をすべて無効として作り直す。文字数比例、均等割り、目標3分からの逆算は使わない。

## 今回の実施範囲

今回のターン境界と台本文面は、ASR、波形、ピッチ分離、強制アラインメントで機械確認した。主観的な試聴は未実施であり、手順1・2・4の人による聞き取り確認を達成済みとは扱わない。画像間で頭部の向きが大きく異なるため、半透明の口元合成や音節ごとの切り替えは採用していない。
