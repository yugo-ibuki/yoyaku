# こたつとみかん

2026-11-01 に Codex 組み込み `image_gen` で作成した、猫の対話動画用の横長画像素材です。ユーザーが採用したベース画像から、左右それぞれの発話画像を生成しました。

## 構成

| ファイル | 内容 |
|---|---|
| `base.png` | 2匹とも口を閉じた基準画像。採用済みの `base-sample.png` と同一バイト |
| `left-speaking.png` | 左の橙色のトラ猫が発話し、右の銀灰色のトラ猫は口を閉じて聞く |
| `right-speaking.png` | 右の銀灰色のトラ猫が発話し、左の橙色のトラ猫は口を閉じて聞く |
| `base-sample.png` | ユーザーが採用した元のサンプル画像 |
| `generation-prompt.txt` | ベース画像生成時の実際のプロンプト |
| `PROMPTS.md` | 左右の発話画像生成時の実際のプロンプト |

3状態とも1672×941 pxです。畳と障子の和室で、赤いこたつ布団、中央のみかん籠、2個の湯飲みを配置しています。既存の `outdoor-cafe/base.png` と `rooftop-work-break/base-sample-v2.png` を猫の識別と画風の参照にしました。これらは生成時の来歴であり、今回の動画が実行時に依存する素材ではありません。

## 確認と利用

生成画像を目視し、各発話画像で話者だけが口を開け、聞き手は閉口していること、2匹の位置と小物の大きな変化がないことを確認しました。生成編集では口元以外にも微細な差が出るため、動画では基準画像に話者の口元だけを合成すると切り替え時のちらつきを抑えられます。

現在の利用例は、[数字・規模中心の新8発話版レンダラー](../../videos/privacy-breaches-2026-sep-oct-scale-dialogue-video/render.py)です。同じ3枚を直接参照し、78.6秒の動画を制作しました。音声・字幕・数字表示の同期検証と全フレーム確認の記録は[同プロジェクト](../../videos/privacy-breaches-2026-sep-oct-scale-dialogue-video/README.md)に保持しています。素材の複製・再生成は行っていません。
