## 台本で使った事実

- ターン1〜4: クラウドセッションは手元のマシン外で実行され、ラップトップを閉じても続く。ブラウザ、モバイル、デスクトップ、ターミナルから開始・確認・操作できる。
- ターン5〜8: 通常はアクセス権のあるGitHubリポジトリをクローンする。リポジトリにコミットした設定やスキルは利用できる一方、ローカルだけのものは通常の開始では自動で入らない。CLIには手元のリポジトリをアップロードする経路があるため、「未コミットファイルは絶対に転送されない」とは表現しない。
- ターン9〜10: クラウド環境は、ネットワークアクセス、環境変数、セットアップスクリプトを制御する保存設定である。
- ターン11〜12: 初期のTrustedネットワークは、主なパッケージ配布元、GitHub、主要クラウドなどの許可先に限定される。一般のニュースサイトやブログは通常含まれないため、外部サイトを扱う用途では必要な宛先を許可する。
- ターン13〜16: 接続先の制限と、人による成果確認を組み合わせる。後半の「会話・変更内容・テスト結果を確認する」は、安全に使うための制作側の実務的な勧めであり、記事からの引用ではない。

台本はすべて独自に言い換え、記事本文を連続して転載していない。料理と厨房の例えは動画用のオリジナル表現。

最終音声のターン8は、生成入力の「スキル」をFaster Whisperと独立CTC ASRがともに「スクリプト」と認識した。最終字幕は音声同期を優先して「スクリプト」としたが、元記事の説明対象にはスキルも含まれる。主観的な試聴は未実施。
