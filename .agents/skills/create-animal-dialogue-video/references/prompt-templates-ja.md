# 動物会話動画の日本語プロンプトテンプレート

必要なテンプレートだけをコピーし、角括弧を案件の内容で置き換える。未確定項目は推測せず、`[未確定]` のまま残す。

## 1. 制作入力シート

```text
【動画の目的】
[用途・掲載先・視聴者]

【動画仕様】
- 画面比率：[例: 16:9 / 9:16 / 1:1]
- 解像度：[幅]×[高さ]
- フレームレート：[fps]
- 目標尺：[目安。実際の最終尺は完成音声を基準にする]
- 画風：[実写風 / 絵本風 / 2Dアニメ / 3Dなど]
- カメラ：[固定 / パン / 寄り引き / カット構成]

【登場キャラクター】
- ID：[制作管理用ID]
  種類：[動物種・品種]
  個体の特徴：[色・模様・体格・年齢表現・服装・持ち物]
  役割：[物語上の役割]
  字幕ラベル：[視聴者に見せる名前または役割名]
  画面内の位置：[位置・向き・他キャラクターとの距離]
  声の制作指示：[声質・高さ・速さ・感情。字幕には表示しない]
  発話時の表情と口・くちばしの動き：[指示]
  聞き手時の表情と動き：[指示]

[登場数に合わせてキャラクター欄を追加]

【場面】
- 背景：[場所・時代・時間帯・天候]
- 照明と色：[指示]
- 小道具：[指示]
- 字幕用の余白：[位置・広さ]
- 入れない要素：[余分な登場物、文字、ロゴ、透かしなど]

【会話素材】
- 元資料：[パスまたは説明 / なし]
- 台本：[パスまたは本文]
- 読み方の注意：[固有名詞・数字・専門語]
- 音声：[最終音声のパス / これから制作]
- 字幕：[全文 / 表示単位 / 最大行数 / 位置 / 書体 / 色]
- BGM・環境音：[内容と会話との音量関係 / なし]

【維持する要素】
[提供素材にあるキャラクターの同一性、模様、衣装、位置、構図など]

【完成条件】
[画質、読みやすさ、同期、ファイル形式、再現素材に関する条件]
```

字幕ラベルには `[字幕ラベル]` だけを使う。`若い女性`、`低い声`、`早口` などの声の制作指示を、字幕上の名前へ流用しない。

### 記入例（犬と小鳥）

```text
- ID：dog-librarian
  種類：大型犬
  個体の特徴：茶色の短毛、丸眼鏡、深緑のベスト
  役割：図書館の司書
  字幕ラベル：司書
  画面内の位置：受付カウンターの奥
  声の制作指示：落ち着いた低めの声、ゆっくり明瞭

- ID：bird-visitor
  種類：黄色い小鳥
  個体の特徴：小柄、翼の先が白い、服は着けない
  役割：本を探す利用者
  字幕ラベル：利用者
  画面内の位置：カウンター手前の止まり木
  声の制作指示：明るく軽い声、自然な会話速度
```

## 2. 基準画像生成プロンプト

```text
[画面比率]、[解像度]の基準画像を1枚作成してください。

場面は[背景]です。画風は[画風]、照明と色調は[照明・色調]、カメラは[画角・高さ・レンズ感]です。

登場する動物は[数]体です。次の欄を各キャラクターについて繰り返してください。
- [キャラクターID]：[動物種・品種]。[個体の特徴]。[役割]。[画面内の位置・向き・姿勢]。

各キャラクターの顔と口またはくちばしが、会話アニメーションに使えるよう明瞭に見える構図にしてください。[字幕位置]に字幕用の余白を確保してください。[提供画像・映像]がある場合、各キャラクターの同一性、色、模様、衣装、体格、相対位置、全体構図を維持してください。

小道具：[小道具]
入れない要素：[余分なキャラクター、不要な文字、ロゴ、透かし、形状の重複など]

この画像には字幕や話者名を描き込まないでください。
```

画像を確認し、動物の数、個体の特徴、位置、口元の視認性、背景、画風、比率、字幕余白が入力シートと一致してから動画工程へ進む。

## 3. 完成動画制作プロンプト

このテンプレートは制作指示をまとめるもの。時刻欄には、最終音声を確認して `sync-dialogue-video` で得た実測値を入れる。

```text
添付の[基準画像のパスまたは識別子]と[最終音声のパスまたは識別子]を使い、[画面比率]、[解像度]、[fps]の動物会話動画を制作してください。動画の長さは最終音声の実測時間に合わせてください。

【維持条件】
[キャラクター数、個体の特徴、衣装、相対位置、背景、構図、画風]

【キャラクターと表示名】
- [キャラクターID]
  種類：[動物種・品種]
  字幕ラベル：[ユーザー指定の名前または役割名]
  声の制作指示：[声質・高さ・速さ・感情。字幕ラベルには使わない]
  発話時：[表情、身振り、その動物に合う口・くちばしの開閉]
  聞き手時：[閉じた口・くちばし、視線、まばたき、呼吸、控えめな反応]
[必要な数だけ追加]

【実測タイムライン】
- 発話ID：[ID]
  話者ID：[キャラクターID]
  実測開始：[00:00.000]
  実測終了：[00:00.000]
  確認済み台詞：[本文]
  字幕ラベル：[ユーザー指定の名前または役割名]
  字幕カード：[実音声へ強制アラインメントした開始・終了時刻と本文]
  表情・動作：[指示]
[全発話を追加]

【同期条件】
最終音声を時刻の正本にしてください。確認済みの話者ターンと字幕カードを、文字数配分、均等間隔、固定秒数へ置き換えないでください。各ターンでは確認済み話者だけが口またはくちばしを発話に合わせて動かし、他のキャラクターは口を閉じて自然な聞き手の反応だけを行います。字幕、話者交代、口・くちばしの動きは同じ実測タイムラインを使ってください。無音だけを根拠に話者交代を決めないでください。

【字幕仕様】
[位置、書体、サイズ、文字色、縁取り、背景、最大行数、改行方針]
表示名は各キャラクターの[字幕ラベル]を使い、年齢、性別表現、声質、音域、話速などの制作指示を表示しないでください。

【音響】
[声、BGM、環境音、音量、フェード、不要音の扱い]

【完成条件】
[必要なファイル形式と画質]。全発話で音声、話者、字幕、口・くちばしの動きが一致し、聞き手の口が誤って動かず、キャラクターの同一性と構図が維持されていること。最終音声、台本、実測タイムライン、制作プロンプト、使用設定、入力素材と生成物の来歴を動画と一緒に保存してください。
```
